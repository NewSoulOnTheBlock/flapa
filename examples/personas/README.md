# Example personas

P.A.C.S ships blank. On first run the dashboard opens the forge, and the persona it writes lands in
`data/personas/<id>.json` with its posting catalog beside it as `<id>.topics.json`.

This folder holds a finished persona to read or start from. **Flapa** was the first agent to live in
P.A.C.S: a kawaii memecoin trader on BNB Chain. To run her, copy both files into `data/personas/`
(or `$FLAPA_HOME/personas/`) and pick her from the persona menu.

A catalog category's `side` is `trading` or `life` (`kawaii` is the older name for `life` and still works).
